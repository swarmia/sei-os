# Build concepts: where to read the *Build* book

**What this is.** The shared map every skill uses to find the right part of Swarmia's book *Build: Elements of an Effective Software Organization* (Rebecca Murphey and Otto Hilska, third edition, 2026). It holds only titles, concept names and links. The book's content is not in this repository: read it on the web, at https://www.swarmia.com/build/.

**How to use it.**
1. Find the leader's question in the **Question router**, or the concept in the **Concept index**.
2. Fetch the linked sections of the web edition and read them before answering. Do not answer from memory of the book or from the names here alone.
3. Cite the section URL you used. Paraphrase; quote only short named concepts (under 15 words).
4. Quote numbers only from `benchmarks.md`. The book deliberately avoids universal targets; never invent one.

**Companion:** `build-framework.md` maps the measurement layer (pillars, metric groups, metrics); its text is at https://www.swarmia.com/framework/. The book is the reasoning behind it.
