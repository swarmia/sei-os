# Decisions

Leadership and engineering decisions worth remembering, one file per decision, named `yyyy-mm-dd-<slug>.md`. Copy [`_template.md`](_template.md).

Record decisions that shape how teams work (a team split, a review policy, a metric you stopped using, a tool rollout), not routine technical choices; those belong in your code repositories' ADRs. Skills use this folder to avoid recommending something you already tried, and to explain why things are the way they are.
