# Survey results

One file per past survey (developer experience, engagement, AI tools), named `yyyy-mm-<survey>.md`. Copy [`_template.md`](_template.md).

Keep results **aggregated**: scores by question at org and team level, with team results only where at least ~5 people answered. Paraphrase comment themes; never paste raw comments or names.

The most useful part of each file is the last section, what you did about it. It lets skills check whether the organization closes its feedback loops.
